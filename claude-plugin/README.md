# Monitly plugin for Claude

Official statistics in Claude: 100,000+ datasets for 150+ countries from Eurostat, OECD, the World Bank, the IMF, WHO and national statistics offices. Read-only, no account needed.

- MCP server: `https://monit.ly/api/mcp/public` (no sign-in)
- Skill: `monitly-statistics` (recommended workflow: search, inspect, then pull the series with its source)
- Docs: https://monit.ly/mcp-docs
- Privacy: https://monit.ly/privacy
- Support: https://monit.ly/contact

Install in Claude Code:

```
/plugin marketplace add ContentWriterco/Monitly-MCP
/plugin install monitly@monitly-plugins
```
